# Spore Siege music

Drop MP3 files here and the game uses them automatically (no code changes). Missing files are fine: the game plays a synth heartbeat instead.

| File | When it plays | Loops |
|---|---|---|
| `music/play.mp3` | During the game | yes |
| `music/gameover.mp3` | Game over screen | no |

## Suno prompts (instrumental)

**play.mp3** (the main loop, 2 to 3 minutes; if Suno gives a track with a long fade-out, trim it so it loops cleanly)
> Driving retro arcade synthwave, 150 BPM, pulsing analog bass arpeggio, bright chiptune lead, tense and urgent, glowing neon insect-swarm vibe, gated snare, rising build-ups, instrumental, no vocals, loopable

**gameover.mp3** (10 to 20 seconds)
> Short dramatic arcade game-over sting, descending synth line, dying power-down, a single low pulse at the end, instrumental, no vocals

Optional extra ideas for later: a calm title track, a faster boss-wave track, a victory jingle.
