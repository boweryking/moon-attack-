# Spore Siege audio

Made with ElevenLabs (music + sound effects). Everything is optional: if a file is missing the game plays a small synth sound instead.

- `music/play.mp3`: instrumental loop during the game (90 s, plays on repeat)
- `music/gameover.mp3`: short game-over sting
- `sfx/`: chomp (caterpillar), croak / croak_happy / croak_sad (frog), spit, splat, dragonfly, fly, spider, scorpion, butterfly, levelup, rustle

To swap one, replace the file with another MP3 of the same name.
